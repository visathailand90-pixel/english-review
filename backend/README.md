# Личный backend читалки
GitHub Pages остаётся фронтендом. Worker работает отдельно, только на Cloudflare Workers Free + D1 Free. Не использовать temporary preview account: нужен постоянный аккаунт владельца.

## Авторизация и данные
/portal открывается как отдельное окно: Safari использует first-party Secure HttpOnly SameSite=Strict cookie. Публичные API не выдают CORS-разрешений. POST принимает только JSON с точным Origin и X-CSRF из закрытой сессии. postMessage проверяет source и origin. Не помещать OpenAI API key или пароль в GitHub Pages, URL, localStorage, отчёты, shell arguments или Git.

Пароль владельца должен быть случайным длинным (не менее 20 символов); его salted SHA-256 хранится в секретах Worker, исходный пароль нигде не записывается приложением. Вход ограничен 5 попытками/IP/час и 20/час глобально. Сессия 24 часа, выход отзывает её. Регистрации нет. Для внешнего аудитора это single-owner прототип с ограничением доступа, не универсальная система аккаунтов.

## Подготовка
1. Проверить вход Codex через ChatGPT. Активировать бонус в правильной API-организации; подтвердить баланс, отсутствие платного баланса/карты/Auto Recharge и дату истечения. Без этого не включать генерацию и не отправлять пробные запросы.
2. Wrangler OAuth login через официальный браузер; проверить Free-план аккаунта. Никаких платных переходов.
3. Создать локальный wrangler.toml вне публичного дерева из шаблона; указать main на worker.mjs, привязать одну D1 DB, выполнить schema.sql. Сначала GENERATION_ENABLED=false.
4. Передать OPENAI_API_KEY через stdin wrangler secret put, не через CLI argument. OWNER_SECRET_SALT и OWNER_SECRET_HASH — только secret store. Владелец вводит пароль через локальный masked input, не в чат.
5. Read-only GET /v1/models проверяет доступ модели без генерации. В OPENAI_MODEL записать подтверждённый реальный model ID, учитывая актуальные deprecations и лимиты. В тестах mock-only-model не является рекомендацией и никогда не отправляется провайдеру.
6. После подтверждения бесплатного режима установить BONUS_ONLY_CONFIRMED=true и BONUS_EXPIRES_AT (ISO UTC с запасом до истечения). Финальный флаг GENERATION_ENABLED=true только после тестов.
7. Проверить одну реальную генерацию после разрешения владельца, словарь всех форм, отсутствие ключа в HTML/DevTools/Git, 401 без сессии, CSRF/origin, сохранение D1 и localStorage. На физическом iPhone тестирует владелец.

## Лимиты и выключение
3 генерации/час, 8/сутки, атомарные D1 reservations до запроса; max_output_tokens=6000, один вызов без ретраев, prompt до 7000 символов контекста. Любой HTTP 429 провайдера выключает генерацию через flags.disabled. /api/disable доступен только владельцу. Повторное включение после ручной проверки бесплатного баланса. Истечение BONUS_EXPIRES_AT блокирует генерацию.
Эти лимиты не заменяют условия биллинга: OpenAI может использовать купленные кредиты, если владелец позднее их добавит. Приложение не имеет надёжного публичного API для проверки типа каждого доллара. Для строгого запрета дополнительных оплат нельзя добавлять платный баланс, карту или auto-recharge. Изменение условий владельцем требует повторной проверки.
Workers Free: 100 000 запросов/сутки, 10 ms CPU; D1 Free: 5 млн прочитанных / 100 000 записанных строк в сутки, 5 GB общего хранения (проверено 2026-11-10). Превышение не является разрешением на платный тариф.

## Сохранение и миграция
Новые тексты сохраняются в D1 через INSERT OR IGNORE по хешу контента; API доступен только после входа. Cloud sync добавляет тексты в локальную библиотеку без замены старых. Старые тексты остаются в chitalka.gen. Экспорт JSON перед переносом обязателен; импорт добавляет конфликты с новым ID. Перенос старого формата в D1 не автоматический: старые словари могут не покрывать каждую форму и не пройти новую строгую схему. Локальные данные от этого не страдают.
Для полного восстановления пользовательских слов сохранять JSON-бэкап. Прогресс упражнений хранится отдельно в старых ключах.
