# English Apps — повторение, читалка, слова

Три приложения в **одном репозитории** GitHub Pages:

- `https://visathailand90-pixel.github.io/english-review/` — повторение уроков (начало — урок 3)
- `https://visathailand90-pixel.github.io/english-review/reader/` — Английская читалка
- `https://visathailand90-pixel.github.io/english-review/words/` — Тренажёр слов

## Обновить работающий сайт

Положите материалы в соседнюю папку inbox и поручите Codex: «Обнови английские приложения». Методология — AGENTS.md. Проверка: `python tools/build.py` и `python tools/test_apps.py` (Python Playwright, Chromium, Node.js). Публикация — `publish-english.ps1` с точным списком проверенных файлов; без -Publish выполняется только проверка.

Новые функции: выпадающий список уроков; по умолчанию 4 задания на странице (1–5 на выбор); две отдельные стадии `Узнаю` (EN→RU, RU→EN); в сборке предложений 3 лишних слова; объяснение ошибки; нет дублирующего режима `Говорю` и вкладки `Слова`. Словарь для узнавания сохранён внутри данных урока.

## Обновление уроков через Codex

Исходники уроков находятся в `lesson-data/*.json`, список уроков — `lesson-data/index.json`. В `app-template.html` используется маркер `__LESSONS_JSON__`. Для пересборки:

```bash
python tools/build.py
```

Затем проверить результат локально и отправить изменённые файлы в репозиторий через `git add / commit / push`. Если настроен Git Credential Manager (`gh auth login`/`git push`), Codex сможет делать этот шаг самостоятельно по запросу.

**Безопасность.** Репозиторий публичный: НИКОГДА не добавляй личные необработанные транскрибации, сканы, API ключи, `.env`, логины, записи занятий. В GitHub отправляется только итоговый проверенный учебный контент. Не удаляй старые JSON, уроки, словари и клиентский `localStorage`.

## Как работает сохранение

Результаты и незаконченные ответы автоматически сохраняются в `localStorage` того устройства и браузера, где занимаешься. Смена `index.html` **не очищает** прогресс, если адрес сайта тот же. Для переноса между iPhone и компьютером — экспорт/импорт JSON. Синхронизация между устройствами автоматически не настроена. В режиме Safari и «На экран Домой» данные могут храниться раздельно: при переходе используй экспорт/импорт.

## Читалка

Готовые встроенные тексты читаются на GitHub Pages. Генератор новых текстов был завязан на `window.claude` и не работает на обычном GitHub Pages; добавляй новые тексты через Codex к статической базе. Для аудио Safari использует `speechSynthesis`, если доступно.

## Техническая проверка

- Публикуем из `main` / root, GitHub Pages по HTTPS.
- Сервис-воркер `sw.js` обеспечивает резервный offline cache после первого посещения, обновляется вместе с пакетом.
- Не изменять ключ прогресса `english-review:v4` без миграции данных.


## Обновление трёх приложений
Теория дополнена подробными блоками с примерами и скрываемой самопроверкой; прежние задания сохранены. Новая лексика — words/bank.json (сборка bank.js); старые две пачки остаются. В словаре есть «Копирую», «Вспоминаю написание», история и JSON-бэкап. Русская транскрипция приблизительная, озвучка использует голоса устройства.
Читалка поддерживает личный OpenAI backend и хранение текстов в D1 + локально. Ключ не попадает во фронтенд. До подтверждения бесплатного бонуса, модели и авторизации владельца генерация отключена; никаких автоматических оплат. Подробности в backend/README.md.
Дополнительные проверки: python tools/test_upgrade.py и node tools/test_backend.mjs. Для WebKit используйте существующий Playwright; при загрузке браузеров установите PLAYWRIGHT_SKIP_BROWSER_GC=1, чтобы не удалять чужие версии из общего кеша.
