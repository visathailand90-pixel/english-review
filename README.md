# English Review — уроки 1–9 и практика 1

Это автономное веб-приложение, подготовленное для Safari на iPhone и бесплатного статического хостинга GitHub Pages / Netlify.

### Публикация на GitHub Pages
1. Создайте **публичный** репозиторий, например `english-review`.
2. Загрузите файлы из этого архива **в корень** репозитория (index.html, sw.js, manifest.webmanifest, icon.png).
3. В Settings → Pages → Build and deployment выберите Deploy from a branch → main → /(root), нажмите Save.
4. Адрес будет https://ВАШ_ЛОГИН.github.io/english-review/ (замените логин и название репозитория).
5. На iPhone откройте ссылку в Safari и выберите Поделиться → На экран «Домой» → Open as Web App / Открывать как веб-приложение.

**Важно о приватности:** GitHub Free Pages использует публичный репозиторий. HTML, включая тексты упражнений и учебные ошибки, будет доступен другим людям, у которых есть ссылка. Для меньшей публичности исходников лучше хостинг, поддерживающий непубличное размещение репозитория, но сам опубликованный сайт все равно доступен по ссылке.

### Работа и хранение прогресса
- Без регистрации и сервера, данные упражнений внутри index.html.
- Результаты и незаконченные блоки автоматически сохраняются через localStorage **в конкретном браузере / веб-приложении**.
- Вкладка «История» хранит ответы, баллы и объяснения; ошибки исчезают после двух правильных ответов подряд.
- Экспорт / импорт JSON нужен для переноса и резервной копии. Прогресс разных устройств автоматически не синхронизируется.
- Вопросы показываются по 2 за раз (можно выбрать 1, 3 или 4); проверяется весь блок после ответов. При проверке страница заданий не переключается сама, ранее выбранные ответы остаются на месте.
- Озвучка включается только если доступен браузерный синтез речи.
- При обновлении URL и домена прогресс другого адреса автоматически не перенесётся.
- Приложение не зависит от сторонних JS-библиотек, шрифтов и внешних API; сервис-воркер может кэшировать его после первой загрузки.

Если старый тренажёр выгружал JSON формата `english-review-v1`, файл можно импортировать из вкладки «История» (сохранятся старые оценки и список ошибок, но без полного текста прошлых ответов).
